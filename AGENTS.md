## About this repository

This repository is maintained by My First Bitcoin, a US nonprofit that empowers independent educators
worldwide with open-source Bitcoin education. Website: https://myfirstbitcoin.org

## Conventions for contributors and AI assistants

- Say "Bitcoin", never "crypto" or "cryptocurrency".
- Write "My First Bitcoin" in full. The website is myfirstbitcoin.org.
- Bitcoin is a tool for sovereignty and freedom: never frame it as an investment, and never give financial advice.
- Educational content teaches how to think, not what to think.
- Never invent numbers or facts; cite your sources.
- No em-dashes in prose; use commas, colons or parentheses.
- Never commit secrets, keys or personal data.
- Propose changes by pull request.
